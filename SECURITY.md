# Política de segurança

Não publique vulnerabilidades, tokens, cookies ou links privados em uma issue.
Use **Security → Report a vulnerability** no GitHub para abrir um *Security
Advisory* privado com a versão afetada, passos mínimos e impacto observado.

As versões suportadas são a Release mais recente e, durante uma atualização,
a versão imediatamente anterior. Binários oficiais são publicados apenas em
GitHub Releases e acompanhados por hashes SHA-256 e atestados de proveniência.
